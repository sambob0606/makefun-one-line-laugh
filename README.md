A Python program that writes one original funny line about everyday life for [The One-Line Laugh](https://make.fun/bounty/u-ronigrv-the-one-line-laugh-7ccca46f) on make.fun.

The line:

> I set my alarm for 6am to seize the day, then spent three hours negotiating with it like a hostage standoff where I was both sides.

## Run it

```sh
python3 main.py
```

It writes the line to `/output/entry.txt`.
